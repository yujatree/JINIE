Program for the Analysis of LPS ... *Like a Genie !*

**- READERS**  

☑︎ READER: DCD Reader (linking)   
☑︎ ENSEMBLE_READER: DCD Reader (ensemble)    
☑︎ D2L: DCD to Lammps trajectory  
  
**- Structure Property List**   
  
☑︎ AGD: Angle Distribution  
☑︎ CLS: Polyanion Clustering  
☑︎ RDF: Radial Distribution Function, $g(r)$  
☑︎ R2X: RDF to X-ray diffraction  
☑︎ R2S: RDF to Neutron diffraction  
  
**- Dynamics Property List**   
  
☑︎ MSD: Mean Squared Displacement, $<r^2(t)>$  
☑︎ NGP: Non-Gaussian Parameter, $\alpha_2(t)$  
☑︎ ICD: Ionic Conductivity, $\sigma$  
☑︎ GSRT: Self-part van Hove correlation function, $G_s(r,t)$  
☑︎ RGRT: Rotational van Hove correlation function, $G_s(\theta,t)$  
□ RNGP: Rotational Non-Gaussian Parameter  
  
**- Hopping analysis**   
  
☑︎ HOP: Hop Function, $h_i(t)$  
☑︎ CDDF: Conditional Distance Distribution Function of each atom (ensemble calculation)  
☑︎ CRDF: Conditional Radial Distribution Function (ensemble calculation)  
□ HSH: Hop shell analysis
